# RND — RND / Random Number Generation

Manual section: **24.2**, page **587**. Index names: RND.

## Purpose
(External Device) Applied Instructions This instruction generates random numbers.

## ST Syntax (GX Works 2)
- `RND(EN,d);`
- `RNDP(EN,d);`

## Operands
- **EN**: Execution condition [Bit]
- **d**: ENO Execution state Operation) (Block Data Applied Instructions [Bit]
- **?**: Head device storing a random number [ANY16]

## Support
- FX3U: ✓
- FX3G: —
