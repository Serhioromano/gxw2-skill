# STMR — STMR / Special Timer

Manual section: **13.6**, page **337**. Index names: STMR.

## Purpose
Processing) (High Speed  Applied Instructions This is the command for creating the off-delay timer, one-shot timer or flicker timer easily.

## ST Syntax (GX Works 2)
- `STMR(EN,s,d);`

## Operands
- **EN**: Execution condition [Bit]
- **s**: Timer to be used [100ms timer] [ANY16]
- **d**: Set value of timer [ANY16]
- **ENO**: Execution state [Bit]
- **?**: variable Beginning bit device to be output [4 points occupied] ARRAY [0..3] OF (optional device)) (External Device Applied Instructions [Bit]

## Support
- FX3U: ✓
- FX3G: —
