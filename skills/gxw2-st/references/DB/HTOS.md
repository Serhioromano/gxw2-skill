# HTOS — HTOS / Hour to Second Conversion

Manual section: **21.5**, page **551**. Index names: HTOS.

## Purpose
(External Device) Applied Instructions This instruction converts the "hour, minute, second" unit (time) data into second unit data.

## ST Syntax (GX Works 2)
- `HTOS(EN,s,d);`
- `HTOSP(EN,s,d);`
- `DHTOS(EN,s,d);`
- `DHTOSP(EN,s,d);`

## Operands
- **EN**: Execution condition [Bit]
- **ENO**: Execution state [Bit]

## Support
- FX3U: ✓
- FX3G: ✓
