# ROTC — ROTC / Rotary Table Control

Manual section: **13.9**, page **346**. Index names: ROTC.

## Purpose
This is a command suited for turning the table by a shortcut route depending on the demanding window when putting on or taking out articles on the rotary table.

## ST Syntax (GX Works 2)
- `ROTC(EN,s,d);`

## Operands
- **EN**: Execution condition [Bit]
- **s**: Number of divisions [ANY16]
- **d**: Number of low speed sections [ANY16]
- **ENO**: Execution state [Bit]

## Support
- FX3U: ✓
- FX3G: —
