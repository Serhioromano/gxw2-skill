# VRSC — VRSC / Volume Scale

Manual section: **15.7**, page **409**. Index names: VRSC.

## Purpose
Processing) (High Speed  Applied Instructions This instruction reads out the value determined in the variable resistor graduations.

## ST Syntax (GX Works 2)
- `VRSC(EN,s,d);`
- `VRSCP(EN,s,d);`

## Operands
- **EN**: Execution condition [Bit]
- **s**: variable Variable resistor number for reading out the graduations (optional device)) (External Device Applied Instructions [ANY16]
- **ENO**: Execution state [Bit]
- **d**: variable Storage destination of variable resistor graduations [ANY16]
