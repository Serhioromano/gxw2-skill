# BAND — BAND / Dead Band Control

Manual section: **29.2**, page **683**. Index names: BAND.

## Purpose
(External Device) Applied Instructions This instruction provides the upper limit value and lower limit value of the dead band for an input numeric value, and controls the output value using these limit values.

## ST Syntax (GX Works 2)
- `BAND(EN,s1,s2,d);`
- `BANDP(EN,s1,s2,d);`
- `DBAND(EN,s1,s2,d);`
- `DBANDP(EN,s1,s2,d);`
