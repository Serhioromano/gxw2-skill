# LEFT — LEFT / Extracting Character String Data from the Left

Manual section: **26.6**, page **637**. Index names: LEFT.

## Purpose
(External Device) Applied Instructions This instruction extracts a specified number of characters from the left end of a specified character string.

## ST Syntax (GX Works 2)
- `LEFT(EN,s,n,d);`
- `LEFTP(EN,s,n,d);`

## Operands
- **EN**: EN Execution condition Operation) (Block Data Applied Instructions [Bit]
- **s**: Head device storing a character string [String]
- **n**: Number of characters to be extracted [ANY16]
- **ENO**: Execution state [Bit]
- **d**: Head device storing extracted character string [String]
- **?**: Control) (Character Applied Instructions [String]
