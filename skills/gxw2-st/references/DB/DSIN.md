# DSIN — DSIN / Floating Point Sine

Manual section: **18.18**, page **482**. Index names: DSIN.

## Purpose
This instruction determines the SIN value of angle (RAD). → As for handling of floating decimal point, refer to FX Structured Programming Manual [Device & Common].

## ST Syntax (GX Works 2)
- `DSIN(EN,s,d);`
- `DSINP(EN,s,d);`

## Operands
- **EN**: Execution condition [Bit]
- **ENO**: Execution state [Bit]

## Support
- FX3U: ✓
- FX3G: —
