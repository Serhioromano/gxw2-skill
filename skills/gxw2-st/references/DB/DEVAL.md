# DEVAL — DEVAL / Character String to Floating Point Conversion

Manual section: **18.5**, page **454**. Index names: DEVAL.

## Purpose
This instruction converts the character string (ASCII code) into binary floating decimal point data. ## ST Syntax (GX Works 2)
- `DEVAL(EN,s,d);`
- `DEVALP(EN,s,d);`

## Operands
- **EN**: Execution condition [Bit]
- **ENO**: Execution state [Bit]
