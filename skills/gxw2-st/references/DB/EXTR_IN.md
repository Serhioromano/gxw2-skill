# EXTR_IN — EXTR_IN / External ROM function

Manual section: **23.1**, page **576**. Index names: EXTR_IN.

## Purpose
This instruction writes the operation control instructions and parameters of the memory for extension function.

## ST Syntax (GX Works 2)
- `EXTR_IN(EN,s);`
- `EXTRP_IN(EN,s);`

## Operands
- **EN**: Execution condition [Bit]
- **s**: • K11: Inverter operation control instruction [ANY16]
- **ENO**: Execution state [Bit]

## Support
- FX3U: —
- FX3G: —
