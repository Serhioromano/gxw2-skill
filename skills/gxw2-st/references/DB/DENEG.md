# DENEG — DENEG / Floating Point Negation

Manual section: **18.16**, page **479**. Index names: DENEG.

## Purpose
This instruction inverts the sign of binary floating decimal point (real number) data. Processing) (High Speed  Applied Instructions → As for handling of floating decimal point, refer to FX Structured Programming Manual [Device & Common].

## ST Syntax (GX Works 2)
- `DENEG(EN,d);`
- `DENEGP(EN,d);`

## Operands
- **EN**: Execution condition [Bit]
- **ENO**: Execution state [Bit]
- **System**: System
- **Operand**: Operand
- **input**: input
- **X000**: D101 D100

## Support
- FX3U: ✓
- FX3G: —
