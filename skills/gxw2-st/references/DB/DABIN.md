# DABIN — DABIN / Decimal ASCII to BIN Conversion

Manual section: **29.5**, page **695**. Index names: DABIN.

## Purpose
(External Device) Applied Instructions This instruction converts numeric data expressed in decimal ASCII codes (30H to 39H) into binary data.

## ST Syntax (GX Works 2)
- `DABIN(EN,s,d);`
- `DABINP(EN,s,d);`
- `DDABIN(EN,s,d);`
- `DDABINP(EN,s,d);`

## Operands
- **s**: Control) (Character Applied Instructions [String]
- **EN**: Execution condition [Bit]
- **ENO**: Execution state [Bit]
- **d**: Device storing conversion result [ANY16/ANY32]

## Support
- FX3U: ✓
- FX3G: —
