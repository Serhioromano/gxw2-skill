# GBIN — GBIN / Gray Code to Decimal Conversion

Manual section: **22.2**, page **569**. Index names: GBIN.

## Purpose
(External Device) Applied Instructions This instruction converts a gray code into a binary value, and transfers it.

## ST Syntax (GX Works 2)
- `GBIN(EN,s,d);`
- `GBINP(EN,s,d);`
- `DGBIN(EN,s,d);`
- `DGBINP(EN,s,d);`

## Operands
- **EN**: Execution condition [Bit]
- **ENO**: Execution state [Bit]
- **s**: variable device storing data after conversion [Word/ANY16/ANY32]

## Support
- FX3U: ✓
- FX3G: ✓
