# DEADD — DEADD / Floating Point Addition

Manual section: **18.8**, page **463**. Index names: DEADD.

## Purpose
This instruction adds two binary floating decimal points. Processing) (High Speed  Applied Instructions → As for program example of floating decimal point operation, refer to section 11.10. → As for handling of floating decimal point, refer to FX Structured Programming Manual [Device & Common].

## ST Syntax (GX Works 2)
- `DEADD(EN,s1,s2,d);`
- `DEADDP(EN,s1,s2,d);`

## Operands
- **EN**: Execution condition [Bit]
- **ENO**: Execution state [Bit]
