# DEBCD — DEBCD / Floating Point to Scientific Notation Conversion

Manual section: **18.6**, page **459**. Index names: DEBCD.

## Purpose
Processing) (High Speed  Applied Instructions This instruction converts the binary floating decimal point in the device into decimal floating decimal point. → As for handling of floating decimal point, refer to FX Structured Programming Manual [Device & Common].

## ST Syntax (GX Works 2)
- `DEBCD(EN,s,d);`
- `DEBCDP(EN,s,d);`

## Operands
- **EN**: Execution condition [Bit]
- **ENO**: Execution state [Bit]
- **s**: variable Device for storing the converted decimal floating decimal point data. 16 [ANY32]
