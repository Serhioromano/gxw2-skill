# DASIN — DASIN / Floating Point Arc Sine

Manual section: **18.21**, page **486**. Index names: DASIN.

## Purpose
This instruction executes SIN-1 operation. → As for handling of floating decimal point, refer to FX Structured Programming Manual [Device & Common].

## ST Syntax (GX Works 2)
- `DASIN(EN,s,d);`
- `DASINP(EN,s,d);`

## Operands
- **EN**: Execution condition [Bit]
- **ENO**: Execution state [Bit]

## Support
- FX3U: ✓
- FX3G: —
