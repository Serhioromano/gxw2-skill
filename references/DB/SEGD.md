# SEGD — SEGD / Seven Segment Decoder

Manual section: **14.4**, page **365**. Index names: SEGD.

## Purpose
Processing) (High Speed  Applied Instructions This is a command for lighting up the 7-segement display unit (1 digit) by decoding the data.

## ST Syntax (GX Works 2)
- `SEGD(EN,s,d);`
- `SEGDP(EN,s,d);`

## Operands
- **EN**: Execution condition [Bit]
- **s**: Beginning word device to be decoded [ANY16]
- **ENO**: Execution state [Bit]
- **d**: variable device for storing 7-segment display data [Word/ANY16]

## Support
- FX3U: ✓
- FX3G: —
