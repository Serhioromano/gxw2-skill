# DESTR — DESTR / Floating Point to Character String Conversion

Manual section: **18.4**, page **447**. Index names: DESTR.

## Purpose
Processing) (High Speed  Applied Instructions This instruction converts the binary floating decimal point data into character string (ASCII code) in a specified number of digits. You can also use the STR instruction for converting BIN data into character string (ASCII code).

## ST Syntax (GX Works 2)
- `DESTR(EN,s1,s2,d1);`
- `DESTRP(EN,s1,s2,d1);`

## Operands
- **EN**: Execution condition [Bit]
- **ENO**: Execution state [Bit]
