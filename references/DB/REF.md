# REF — REF / Refresh

Manual section: **12.1**, page **255**. Index names: REF.

## Purpose
Processing) (High Speed  Applied Instructions This instruction immediately outputs the latest input (X) information or the current output (Y) operation result in the middle of a sequence program operation.

## ST Syntax (GX Works 2)
- `REF(EN,d,n);`
- `REFP(EN,d,n);`

## Operands
- **EN**: Execution condition [Bit]
- **d**: Input variable [Bit]
- **n**: Number of bit devices to be refreshed [ANY16]
- **ENO**: Output variable [Bit]

## Support
- FX3U: ✓
- FX3G: ✓
