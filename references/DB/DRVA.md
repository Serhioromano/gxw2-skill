# DRVA — DRVA / Drive to Absolute

Manual section: **20.8**, page **537**. Index names: DRVA.

## Purpose
Processing) (High Speed  Applied Instructions This instruction performs one-speed positioning by absolute drive. The moving distance from the origin (0 point) is specified, and this is also called absolute driving method.

## ST Syntax (GX Works 2)
- `DRVA(EN,s1,s2,d1,d2);`
- `DDRVA(EN,s1,s2,d1,d2);`
