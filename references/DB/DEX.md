# DEX — DEXP / Floating Point Exponent

Manual section: **18.12**, page **471**. Index names: DEXP.

## Purpose
Processing) (High Speed  Applied Instructions This instruction executes exponential operation whose base is "e (2.71828)". → As for handling of floating decimal point, refer to FX Structured Programming Manual [Device & Common].

## ST Syntax (GX Works 2)
- `DEXP(EN,s,d);`
- `DEXPP(EN,s,d);`

## Operands
- **EN**: Execution condition [Bit]
- **ENO**: Execution state [Bit]

## Support
- FX3U: ✓
- FX3G: —
