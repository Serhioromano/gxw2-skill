# ZPO — ZPOP / Batch POP of Index Register

Manual section: **17.2**, page **437**. Index names: ZPOP.

## Purpose
Processing) (High Speed  Applied Instructions This instruction returns the contents of index registers V0 to V7, Z0 to Z7 once retracted by the ZPUSH instruction to the original state. → As for ZPUSH instruction, refer to section 17.1.

## ST Syntax (GX Works 2)
- `ZPOP(EN,d);`
- `ZPOPP(EN,d);`

## Operands
- **EN**: Execution condition [Bit]
- **ENO**: Execution state [Bit]

## Support
- FX3U: ✓
- FX3G: —
