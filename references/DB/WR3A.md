# WR3A — WR3A / Write to Dedicated Analog Block

Manual section: **22.4**, page **573**. Index names: WR3A.

## Purpose
(External Device) Applied Instructions This instruction writes a digital value to the analog block FX0N-3A and FX2N-2DA.

## ST Syntax (GX Works 2)
- `WR3A(EN,s);`
- `WR3AP(EN,s);`

## Operands
- **EN**: Execution condition [Bit]
- **s**: Analog output channel Control) (Character Applied Instructions [String/ANY16]
- **?**: Data to be written or word device storing data to be written. [ANY16]
- **ENO**: Execution state [Bit]

## Support
- FX3U: ✓
- FX3G: ✓
