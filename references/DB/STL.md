# STL — STL

Manual section: **6.2**, page **100**. Index names: STL.

## Purpose
In programs using step ladder instructions, a state relay State S is assigned to each process based on machine operations, and input condition and output control are programmed as sequences connected to the state output. STL instruction for step ladder programs is expressed as follows in each language.

## ST Syntax (GX Works 2)
- `STL(EN,s);`

## Operands
- **EN**: Execution condition
- **s**: Target device or variable [Bit]
- **ENO**: Execution state [Bit]

## Support
- FX3U: ✓
- FX3G: ✓
