# DCOS — DCOS / Floating Point Cosine

Manual section: **18.19**, page **484**. Index names: DCOS.

## Purpose
This instruction determines the COS value of angle (RAD). → As for handling of floating decimal point, refer to FX Structured Programming Manual [Device & Common].

## ST Syntax (GX Works 2)
- `DCOS(EN,s,d);`
- `DCOSP(EN,s,d);`

## Operands
- **EN**: Execution condition [Bit]
- **ENO**: Execution state [Bit]

## Support
- FX3U: ✓
- FX3G: —
