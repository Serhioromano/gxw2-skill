# DUTY — DUTY / Timing Pulse Generation

Manual section: **24.3**, page **589**. Index names: DUTY.

## Purpose
(External Device) Applied Instructions This instruction generates the timing signal whose one cycle corresponds to the specified number of operation cycles.
