# DLOGE — DLOGE / Floating Point Natural Logarithm

Manual section: **18.13**, page **473**. Index names: DLOGE.

## Purpose
Processing) (High Speed  Applied Instructions This instruction executes natural logarithm operation.

## ST Syntax (GX Works 2)
- `DLOGE(EN,s,d);`
- `DLOGEP(EN,s,d);`

## Operands
- **EN**: Execution condition [Bit]
- **ENO**: Execution state [Bit]

## Support
- FX3U: ✓
- FX3G: —

## Examples (ST, from the manual)
```iecst
DLOGE(X000,D40,D30);
```
