# SFRD — SFRD / Shift Read [FIFO Control]

Manual section: **10.10**, page **222**. Index names: SFRD.

## Purpose
This instruction reads data for first-in first-out control.

## ST Syntax (GX Works 2)
- `SFRD(EN,s,n,d);`
- `SFRDP(EN,s,n,d);`

## Operands
- **EN**: Execution condition [Bit]
- **s**: Head word device storing data [ANY16]
- **ENO**: Execution state [Bit]
- **n**: Word device storing data taken out first [ANY16]
