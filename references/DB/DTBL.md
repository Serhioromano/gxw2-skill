# DTBL — DTBL / Batch Data Positioning Mode

Manual section: **20.3**, page **523**. Index names: DTBL.

## Purpose
Processing) (High Speed  Applied Instructions Instructions should be set in a data table beforehand using GX Works2. This instruction specifies one table and operates instructions in that table. → As for explanation of the instruction, see the positioning control manual.

## ST Syntax (GX Works 2)
- `DTBL(EN,n,d);`

## Operands
- **EN**: Execution condition [Bit]
- **n**: Table number to be executed (n=1 to 100) [ANY32]
- **ENO**: Execution state [Bit]
- **d**: variable Device for issuing pulse (Y) (optional device)) (External Device Applied Instructions [Bit]
