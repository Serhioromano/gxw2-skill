# DESQR — DESQR / Floating Point Square Root

Manual section: **18.15**, page **477**. Index names: DESQR.

This instruction executes the square root operation of binary floating decimal point. Processing) (High Speed  Applied Instructions → As for handling of floating decimal point, refer to FX Structured Programming Manual [Device & Common].
