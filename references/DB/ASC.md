# ASC — ASC / ASCII Code Data Input

Manual section: **14.7**, page **376**. Index names: ASC.

## Purpose
This instruction converts the 1-byte alphanumeric character string into ASCII code. This is used when selecting and displaying plural messages in the external display unit.

## ST Syntax (GX Works 2)
- `ASC(EN,s,d);`

## Operands
- **EN**: Execution condition [Bit]
- **ENO**: Execution state [Bit]
- **s**: Head device for storing ASCII code [ANY_SIMPLE]

## Support
- FX3U: ✓
- FX3G: —
