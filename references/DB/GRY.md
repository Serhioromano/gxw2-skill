# GRY — GRY / Decimal to Gray Code Conversion

Manual section: **22.1**, page **567**. Index names: GRY.

## Purpose
(External Device) Applied Instructions This instruction converts a binary value into a gray code, and transfers it.

## ST Syntax (GX Works 2)
- `GRY(EN,s,d);`
- `GRYP(EN,s,d);`
- `DGRY(EN,s,d);`
- `DGRYP(EN,s,d);`

## Operands
- **EN**: Execution condition [Bit]
- **ENO**: Execution state [Bit]
- **s**: variable device storing data after conversion [Word/ANY16/ANY32]

## Support
- FX3U: ✓
- FX3G: ✓
