# RD3A — RD3A / Read form Dedicated Analog Block

Manual section: **22.3**, page **571**. Index names: RD3A.

## Purpose
(External Device) Applied Instructions This instruction reads an analog input value from the analog block FX0N-3A or FX2N-2AD.

## ST Syntax (GX Works 2)
- `RD3A(EN,d);`
- `RD3AP(EN,d);`

## Operands
- **EN**: EN Execution condition Operation) (Block Data Applied Instructions [Bit]
- **d**: Analog input channel [ANY16]
- **ENO**: Execution state [Bit]
- **?**: Control) (Character Applied Instructions [String]
- **?**: Word device storing the read data [ANY16]

## Support
- FX3U: ✓
- FX3G: ✓
