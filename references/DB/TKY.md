# TKY — TKY / Ten Key Input

Manual section: **14.1**, page **353**. Index names: TKY.

## Purpose
Processing) (High Speed  Applied Instructions This is a command for setting data in the timer or counter by the input of numeric keys 0 to 9.

## ST Syntax (GX Works 2)
- `TKY(EN,s,d1,d2);`
- `DTKY(EN,s,d1,d2);`
