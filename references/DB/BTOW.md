# BTOW — BTOW / BYTE to WORD

Manual section: **19.3**, page **503**. Index names: BTOW.

## Purpose
Processing) (High Speed  Applied Instructions This instruction couples the lower 8 bits (lower byte) of continuous 16-bit data.

## ST Syntax (GX Works 2)
- `BTOW(EN,s,n,d);`
- `BTOWP(EN,s,n,d);`

## Operands
- **EN**: Execution condition [Bit]
- **s**: Head device for storing the data to be coupled in byte unit. [ANY16]
- **n**: Number of byte data to be coupled (0≤n) [ANY16]
- **ENO**: Execution state [Bit]
- **d**: Head device for storing the coupled result in byte unit. [ANY16]
