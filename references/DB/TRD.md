# TRD — TRD / Read RTC data

Manual section: **21.7**, page **557**. Index names: TRD.

## Purpose
(External Device) Applied Instructions The clock data is read out in the real-time clock built in the PLC. When using FX2NC PLC, optional memory board for Real time clock is required.

## ST Syntax (GX Works 2)
- `TRD(EN,d);`
- `TRDP(EN,d);`
