# SER — SER / Search a Data Stack

Manual section: **13.2**, page **323**. Index names: SER.

## Purpose
Processing) (High Speed  Applied Instructions This is a command for searching same data and maximum value, minimum value from the table of data.

## ST Syntax (GX Works 2)
- `SERP(EN,s1,s2,n,d);`
- `DSER(EN,s1,s2,n,d);`
- `DSERP(EN,s1,s2,n,d);`

## Operands
- **EN**: Execution condition [Bit]
- **ENO**: Execution state [Bit]

## Support
- FX3U: ✓
- FX3G: ✓
