# SEGL — SEGL / Seven Segment With Latch

Manual section: **14.5**, page **367**. Index names: SEGL.

## Purpose
Processing) (High Speed  Applied Instructions This is a command for controlling the 7-segment display unit with latch of 4 digits and 1 set or 4 digits and 2 sets.

## ST Syntax (GX Works 2)
- `SEGL(EN,s,n,d);`

## Operands
- **EN**: Execution condition [Bit]
- **s**: • n=K(H)0 to K(H)3: 1 point occupied [ANY16]
- **Parameter**: Parameter [ANY16]
- **ENO**: Execution state [Bit]
- **n**: • n=K(H)0 to K(H)3: 8 points occupied [Bit]

## Support
- FX3U: ✓
- FX3G: ✓
