# FINS — FINS / Inserting Data to Tables

Manual section: **27.2**, page **657**. Index names: FINS.

## Purpose
(External Device) Applied Instructions This instruction inserts data into an arbitrary position in a data table.

## ST Syntax (GX Works 2)
- `FINS(EN,s,n,d);`
- `FINSP(EN,s,n,d);`

## Operands
- **EN**: EN Execution condition Operation) (Block Data Applied Instructions [Bit]
- **s**: Device storing inserted data [ANY16]
- **n**: Data insertion position in table [ANY16]
- **ENO**: Execution state [Bit]
- **d**: Head device in data table [ANY16]

## Support
- FX3U: ✓
- FX3G: —
